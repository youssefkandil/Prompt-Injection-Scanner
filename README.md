# تشغيل واجهة Prompt Injection Scanner

## تشغيل الصفحة محليًا

افتح PowerShell واكتب:

```powershell
Set-Location C:\prompt-injection-scanner-build
.\.venv-training312\Scripts\python.exe -m streamlit run streamlit_app.py --server.address 127.0.0.1 --server.port 8501 --server.headless true
```

ثم افتح `http://127.0.0.1:8501` في المتصفح. لإيقاف الصفحة ارجع لنافذة PowerShell واضغط `Ctrl+C`.

## تجربة الهدف المحلي

اختر **هدفي المحلي (أقدر أحسّنه)**. لا تحتاج API Key. اختر ملف الهجمات وعددها، واترك علامة الاختبار التجريبية كما هي، ثم اضغط **ابدأ الفحص**. أول طلب يحمل نموذج `Qwen/Qwen3.5-0.8B`؛ قد يأخذ وقتًا على CPU. لو نجحت هجمات، يظهر زر تدريب الهدف المحلي وإعادة الفحص. التدريب يضيف محول LoRA في `finetuning/output/streamlit-adapter` ولا يغيّر النموذج الأساسي.

## تجربة API خارجي

اختر **API خارجي (فحص وتقرير فقط)** ثم أدخل عنوان الخدمة، ومسار Chat Completions، واسم النموذج، ومفتاح API. مثال لخدمة OpenAI-compatible: عنوان ينتهي بـ `/v1` ومسار `/chat/completions`. استخدم علامة اصطناعية موجودة في تعليمات اختبار التطبيق؛ لا تضع كلمة مرور أو سرًا حقيقيًا. المفتاح لا يضاف إلى التقرير ولا إلى ملف إعدادات، لكن طلبات الفحص تذهب إلى مزود الخدمة الذي أدخلته. زر التدريب المحلي لا يظهر لهذا الاختيار.

## ملاحظات

- ملفات التقارير JSON وMarkdown تحفظ داخل `reports/`، وتتضمن نصوص الهجمات وردود الهدف.
- الأحكام التي لا تحسمها علامة الاختبار تستخدم حَكَم Ollama المحدد داخل `scanner/llm_judge.py`؛ شغّل Ollama والنموذج المحدد هناك للحصول على هذه الأحكام.
- انخفاض نتيجة الهجمات على نفس الملف بعد التدريب هو عرض تجريبي على هذه العينة، وليس إثباتًا أن النموذج أصبح آمنًا ضد هجمات جديدة.
- لا تفحص خدمة لا تملكها أو ليس لديك تصريح لاختبارها.
