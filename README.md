# تشغيل واجهة Prompt Injection Scanner

## تشغيل الواجهة الاحترافية على Windows

من داخل مجلد المشروع افتحي PowerShell ونفذي:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

لتحميل موديل Qwen والتدريب المحلي، ثبتي نسخة PyTorch المناسبة للجهاز من صفحة التثبيت الرسمية أولًا، ثم ثبتي:

```powershell
.\.venv\Scripts\python.exe -m pip install -r finetuning\requirements.txt
```

بعدها شغّلي الواجهة الاحترافية:

```powershell
.\.venv\Scripts\python.exe -m streamlit run streamlit_app_pro.py
```

ثم افتحي الرابط الذي يظهر في نافذة PowerShell. لإيقافها اضغطي `Ctrl+C` في النافذة نفسها. لو نسخة Python 3.12 غير موجودة، ثبتيها أو غيّري رقم الإصدار في أول أمر إلى إصدار متاح ومتوافق مع PyTorch.

## تجربة الهدف المحلي

اختر **Local Qwen**. لا تحتاج API Key. اختر ملف الهجمات وعددها، واترك علامة الاختبار التجريبية كما هي، ثم شغّل الفحص. أول طلب يحمل نموذج `Qwen/Qwen3.5-0.8B`؛ قد يأخذ وقتًا في تحميل النموذج. زر التدريب المحلي يستخدم 44 هجمة من عائلتي `ai-sec` و`gandalf`، بالإضافة إلى 20 سؤالًا عاديًا. هجمات `deepset` و`hackaprompt` الـ20 محفوظة للتقييم ولا تدخل في التدريب. التدريب ينشئ محول LoRA في `finetuning/output/streamlit-adapter-reviewed` ولا يغيّر النموذج الأساسي. لو عندك محول قديم محفوظ باسم `streamlit-adapter`، يظل موجودًا ويستمر استخدامه إلى أن يكتمل تدريب المحول الجديد.

## تجربة API خارجي

اختر **External API** ثم أدخل عنوان الخدمة، ومسار Chat Completions، واسم النموذج، ومفتاح API. مثال لخدمة OpenAI-compatible: عنوان ينتهي بـ `/v1` ومسار `/chat/completions`. استخدم علامة اصطناعية موجودة في تعليمات اختبار التطبيق؛ لا تضع كلمة مرور أو سرًا حقيقيًا. المفتاح لا يضاف إلى التقرير ولا إلى ملف إعدادات، لكن طلبات الفحص تذهب إلى مزود الخدمة الذي أدخلته. التدريب متاح للهدف المحلي فقط.

## ملاحظات

- ملفات التقارير JSON وMarkdown تحفظ داخل `reports/`، وتتضمن نصوص الهجمات وردود الهدف.
- الأحكام التي لا تحسمها علامة الاختبار تستخدم حَكَم Ollama المحدد داخل `scanner/llm_judge.py`؛ شغّل Ollama والنموذج المحدد هناك للحصول على هذه الأحكام.
- انخفاض نتيجة الهجمات على نفس الملف بعد التدريب هو عرض تجريبي على هذه العينة، وليس إثباتًا أن النموذج أصبح آمنًا ضد هجمات جديدة.
- لا تفحص خدمة لا تملكها أو ليس لديك تصريح لاختبارها.
- قبل إعادة نشر حالات الهجمات، راجع شروط المصادر المنسوبة إليها وأضف الإسناد أو الترخيص المطلوب. لا يوجد في هذا المستودع حتى الآن ملف ترخيص عام للمشروع.
